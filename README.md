---

## ✨ Все функции (Список возможностей)

Расширение предоставляет полный набор инструментов для работы с Telegram Bot API:

1. **📡 Подключение и авторизация**
   * Установка токена бота.
   * Установка Chat ID по умолчанию (чтобы не писать его в каждом блоке).
   * Проверка статуса подключения к API (возвращает имя бота).
2. **📤 Отправка контента**
   * Отправка текстовых сообщений.
   * Отправка фото по прямой ссылке (URL).
   * Отправка картинки текущего (или конкретного по имени) спрайта в формате PNG.
   * Отправка снимка всей сцены (скриншота экрана) в формате PNG.
3. **🔨 Конструктор меню (Inline-кнопки)**
   * Очистка текущего меню.
   * Разделение кнопок на новые строки.
   * Добавление кнопок-действий (с `callback_data`).
   * Добавление кнопок-ссылок (ведут на сайты).
   * Подсчет количества кнопок в меню.
   * Отправка сообщения с прикрепленным меню.
4. **📥 Приём сообщений**
   * Запуск и остановка фонового приёма обновлений от Telegram (Long Polling).
   * Проверка статуса приёма (активен/не активен).
   * Отслеживание команд (например, `/start`, `/шимбанинка`).
   * Отслеживание любого текста (поиск подстроки).
   * Получение текста и имени отправителя последнего сообщения.
   * Очистка очереди сообщений.
5. **👆 Обработка нажатий на кнопки**
   * Отслеживание нажатия конкретной кнопки (по её `callback_data`).
   * Отслеживание нажатия *любой* кнопки.
   * Получение данных и имени отправителя последнего нажатия.
   * Просмотр и очистка очереди нажатий.
6. **✏️ Редактирование сообщений**
   * Изменение текста сообщения, на котором была нажата кнопка (с полным удалением кнопок).
   * Изменение текста сообщения с прикреплением нового (собранного) меню.

## 📦 Установка

1. Скачайте файл `telegram-extension.js` из этого репозитория.
2. Откройте [TurboWarp](https://turbowarp.org/) и создайте/откройте проект.
3. Нажмите на кнопку **«Добавить расширение»** (иконка с плюсом в левом нижнем углу).
4. Выберите **«Custom Extension»** (Пользовательское расширение).
5. На вкладке **«Files»** выберите скачанный `.js` файл и нажмите **«Load»**.
   *(Или на вкладке «Text» просто вставьте весь код).*
6. ⚠️ **Важно**: Снимите галочку **«Run extension without sandbox»** (Запускать без песочницы). Расширению нужен доступ к сети и рендереру.
